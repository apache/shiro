# Security

Apache Shiro's security model and disclosure process are
published on the project website rather than in the repository:

- **Threat and security model**:
  <https://shiro.apache.org/security-model.html>
- **Security policy, vulnerability reporting, past advisories and CVEs**:
  <https://shiro.apache.org/security-reports.html>
- [Supported versions](https://shiro.apache.org/support.html#supported-versions)
- [Verifying releases](https://shiro.apache.org/download.html#release_process)
- [Security self-assessment](./SECURITY-SELF-ASSESSMENT.md)
- [Dependency policy](./CONTRIBUTING.md#dependency-policy)
- [Security Insights](./security-insights.yml)

The project website is the authoritative source; this file
exists so agents and tooling that look for `SECURITY.md` in
the repository can mechanically follow the link to the
canonical documents.

## Reporting a vulnerability

Report undisclosed security vulnerabilities **privately** to
[security@shiro.apache.org](mailto:security@shiro.apache.org).
Do not open public issues, pull requests or discussions for
vulnerabilities that have not been fixed and announced.
